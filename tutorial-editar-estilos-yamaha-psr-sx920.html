¿Qué es un Style?

El concepto fundamental antes de tocar cualquier herramienta.

En un Yamaha PSR-SX920, un Style es mucho más que un archivo MIDI.

Un Style contiene diferentes patrones de acompañamiento que el teclado combina mientras tocamos acordes con la mano izquierda.

Secciones de un Style

Por ejemplo:

  • Intro 1
  • Intro 2
  • Intro 3
  • Main A
  • Main B
  • Main C
  • Main D
  • Fill In
  • Break
  • Ending

Pistas dentro de cada sección

Dentro de cada sección existen diferentes pistas, por ejemplo:

  • Rhythm 1
  • Rhythm 2
  • Bass
  • Chord 1
  • Chord 2
  • Pad
  • Phrase 1
  • Phrase 2
Info Por eso un Style puede parecerse a una canción MIDI, pero no es simplemente una canción MIDI.

CASM y formatos SFF

Además, Yamaha utiliza información especial que determina cómo reaccionan las notas del acompañamiento cuando cambiamos de acorde.

Esta información está relacionada con CASM y con el formato SFF / SFF2 / SFF GE.

Advertencia importante

Error · No hagas esto No abras un Style del SX920 con cualquier editor MIDI y lo guardes.

Esto puede destruir información necesaria para que el Style funcione correctamente.

Un editor MIDI convencional entiende las pistas MIDI, pero puede no conservar correctamente la información específica del Style Yamaha.

Por eso utilizaremos herramientas que entienden Styles Yamaha.

Primera herramienta: Style Creator del PSR-SX920

La base de todo. Sin ordenador.

¿Qué es?

Es el sistema integrado en el propio SX920 para crear y editar Styles.

No necesitamos ordenador para empezar.

Es la herramienta que debemos aprender primero porque permite comprender qué estamos intentando editar posteriormente en el ordenador.

Funciones documentadas en el manual de referencia del SX920

El manual de referencia del SX920 documenta funciones como:

Grabación en tiempo real Grabación por pasos Style Assembly Channel Edit SFF Edit Drum Setup

Primer ejercicio: desmontar un Style existente

Antes de crear nada, vamos a estudiar un Style que ya funcione.

Objetivo

Aprender qué contiene realmente un Style.

Acción

En el SX920:

  1. Selecciona un Style de fábrica.
  2. Entra en Style Creator.
  3. Examina sus diferentes secciones.
  4. Observa las pistas disponibles.
  5. Observa qué instrumentos utiliza cada pista.
  6. No modifiques nada todavía.

Qué debemos descubrir

Queremos responder:

  • ¿Qué hace Rhythm 1?
  • ¿Qué hace Rhythm 2?
  • ¿Dónde está el bajo?
  • ¿Qué pistas contienen acordes?
  • ¿Qué diferencia existe entre Main A y Main B?
  • ¿Qué ocurre cuando utilizamos un Fill?
  • ¿Qué información cambia cuando cambiamos de acorde?

No hace falta memorizar nada.

Segundo ejercicio: Style Assembly

Esta es una de las funciones más interesantes para empezar.

Style Assembly permite utilizar partes de diferentes Styles para construir otro Style.

Por ejemplo:

STYLE A
Main A
       ↓
STYLE B
Main B
       ↓
STYLE C
Fill
       ↓
STYLE D
Ending

Podemos terminar con:

NUEVO STYLE

Intro      ← Style A
Main A     ← Style A
Main B     ← Style B
Main C     ← Style C
Main D     ← Style C
Fill       ← Style B
Ending     ← Style D

Esto permite crear Styles nuevos sin tener que programar todas las notas desde cero.

Buscamos aprender cómo funciona el sistema.

Tercera herramienta: Yamaha MIDI Song to Style

De una canción MIDI a un Style utilizable.

¿Qué es?

Es una herramienta oficial de Yamaha para Windows y macOS que convierte archivos MIDI en Styles.

Para nosotros es especialmente interesante porque Yamaha indica compatibilidad con el PSR-SX920.

La versión 1.2.0 es compatible con el SX920.

¿Qué problema resuelve MIDI Song to Style?

Imaginemos que tenemos:

cancion.mid

y queremos convertirla en:

cancion.sty

para utilizarla como Style en el SX920.

El programa permite preparar el MIDI y asignar diferentes partes a las secciones del Style.

Por ejemplo:

MIDI
 │
 ├── compases 1-4
 │       ↓
 │     Intro
 │
 ├── compases 5-12
 │       ↓
 │     Main A
 │
 ├── compases 13-20
 │       ↓
 │     Main B
 │
 ├── compases 21-22
 │       ↓
 │     Fill
 │
 └── compases finales
         ↓
       Ending

¿Por qué esta herramienta es importante?

Porque permite hacer algo muy potente:

partir de música MIDI existente en lugar de tocar manualmente todos los patrones.

Por ejemplo, podemos tener un MIDI de:

una canción de blues

y utilizarlo como material para construir un Style de blues.

Pero hay que recordar algo:

Un MIDI de una canción normalmente está pensado para reproducir una composición concreta.

Un Style debe funcionar con muchos acordes diferentes.

Por eso convertir un MIDI en Style no significa automáticamente que el resultado vaya a ser bueno.

Cuarta herramienta: StyleMagic YA

Aquí empieza la edición avanzada desde el ordenador.

¿Qué es?

StyleMagic YA es un editor específico para Styles Yamaha.

El fabricante indica actualmente:

  • publicada en junio de 2026;
  • Windows 10/11;

Esto lo convierte en una de las herramientas más interesantes para estudiar seriamente la creación de Styles en PC.

CASM y CasmEdit

La parte más difícil de entender de los Styles Yamaha.

¿Qué significa CASM?

CASM es una de las partes más difíciles de entender de los Styles Yamaha.

No necesitamos dominarlo todavía.

Para empezar podemos pensar:

CASM contiene reglas que indican al teclado cómo debe comportarse el acompañamiento.

Por ejemplo, cuando tocamos:

C

el Style debe comportarse de una determinada manera.

Si cambiamos a:

F

el teclado tiene que adaptar el acompañamiento.

Y si tocamos:

Am

debe adaptarlo otra vez.

CASM interviene en buena parte de esa lógica.

¿Por qué no basta con cambiar las notas?

Porque podemos tener una pista MIDI perfectamente correcta y aun así obtener un Style que:

  • transponga mal;
  • utilice notas incorrectas;
  • responda mal a determinados acordes;
  • tenga problemas de rango;
  • reproduzca determinados patrones de forma extraña.

Por eso la edición avanzada de Styles requiere entender:

MIDI + estructura del Style + CASM.

Sexta herramienta: CasmEdit

CasmEdit tiene un objetivo mucho más específico:

editar CASM.

No es la herramienta que debemos aprender primero.

Es una herramienta para cuando ya entendemos:

  • Styles;
  • secciones;
  • pistas;
  • MIDI;
  • transposición;
  • comportamiento de acordes.

¿Cuándo necesitamos CasmEdit?

Un ejemplo conceptual:

Tenemos un patrón de bajo que suena perfectamente con:

C

pero cuando tocamos:

F

el resultado no es el esperado.

Puede ser necesario revisar las reglas que controlan cómo se transforma ese patrón.

Ahí es donde entra CASM.

Quinta herramienta: MixMaster

Trabajar con Styles Yamaha existentes sin perder su estructura.

MixMaster es especialmente interesante para trabajar con Styles Yamaha existentes.

Su utilidad principal es diferente de la de MIDI Song to Style.

Podemos pensar:

MIDI Song to Style
        ↓
CREAR STYLE DESDE MIDI

MixMaster
        ↓
MODIFICAR STYLE EXISTENTE

¿Para qué utilizar MixMaster?

Por ejemplo:

Tenemos:

MI_STYLE.STY

y queremos:

  • cambiar batería;
  • cambiar bajo;
  • modificar una frase;
  • sustituir una voz;
  • modificar determinadas notas;
  • trabajar sobre una sección existente.

MixMaster permite trabajar con el contenido del Style manteniendo información que un editor MIDI convencional podría perder.

MixMaster + editor MIDI

Aquí aparece una técnica utilizada por usuarios avanzados.

El concepto es:

STYLE
  ↓

  ↓
MIDI
  ↓
EDITOR MIDI
  ↓

  ↓

La ventaja es que podemos utilizar un editor MIDI potente para modificar las notas y eventos musicales mientras MixMaster se ocupa de la estructura del Style.

Pero para nuestro SX920 hay una consideración importante:

El mundo moderno Yamaha utiliza SFF2/SFF GE.

Por eso no la utilizaría como herramienta principal para el SX920 hasta entender las diferencias entre formatos.

EMC Style Works es un programa veterano de conversión y edición de Styles.

Puede resultar útil para determinados trabajos y conversiones.

Pero es software antiguo.

La estudiaremos solamente si aparece una necesidad concreta.

XGWorks es un antiguo software de Yamaha para MIDI.

Es interesante históricamente y algunos usuarios avanzados todavía lo utilizan.

Pero no debemos pensar:

XGWorks = editor de Styles SX920

No es así.

Su utilidad aparece principalmente en determinados flujos de trabajo combinándolo con otras herramientas, especialmente MixMaster.

¿Qué significa SFF, SFF1, SFF2 y SFF GE?

Una de las partes que más confunde a los principiantes.

No necesitamos memorizar las siglas todavía.

La idea básica es:

SFF
 │
 ├── formatos antiguos
 │
 └── formatos modernos
       │
       └── SFF2 / SFF GE

El SX920 pertenece a la generación moderna.

Por eso debemos prestar especial atención a que una herramienta realmente conserve la información necesaria para SFF GE.

Advertencia Si una herramienta no conserva correctamente la información SFF GE, el Style resultante puede no funcionar como esperas en el PSR-SX920.
